# Sistema de Registro de Estudiantes (API PHP y MySQL)

Proyecto desarrollado para la materia de **Diseño y Programación Web III**. Consiste en un sistema web conectado a una base de datos MySQL mediante PHP para gestionar y visualizar el estado académico de los estudiantes.

## Tecnologías utilizadas
- PHP
- MySQL / XAMPP
- HTML / CSS / JavaScript
- Git y GitHub
